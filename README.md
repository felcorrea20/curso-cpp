# C++ Intermediário

Repositório com os códigos e exercícios desenvolvidos ao longo de um curso de C++ intermediário.
Link: https://www.udemy.com/course/cplusplus-intermediario

## 📖 Sobre

Este repositório reúne o material prático produzido durante o curso, organizado por tópicos, com o objetivo de servir tanto como registro de aprendizado quanto como referência futura.

## 🚀 Como compilar e executar

Cada pasta contém arquivos `.cpp` independentes. Exemplo de compilação usando `g++`:

```bash
g++ -Wall {nome_arquivo} -o {nome_executavel}
./{nome_executavel}
```

## 🛠️ Tecnologias

- **Linguagem:** C++ (padrão C++17)
- **Compilador:** g++
